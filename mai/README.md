# Challenge Angular - Mai

Ce dossier regroupe les enonces, les helpers et les corrections du challenge Angular de mai.

## Structure

- `enonces/level-1.md` : sujet du Level 1.
- `enonces/level-2.md` : sujet du Level 2.
- `enonces/level-3.md` : sujet du Level 3.
- `helpers/` : fichiers fournis avec les enonces.
- `corrections/level-1/` : correction issue de la branche `master`.
- `corrections/level-2/` : correction issue de la branche `level-2`.
- `corrections/level-3/` : correction issue de la branche `level-3`.

Chaque correction est un projet Angular autonome.

## Lancer Une Correction

Depuis le dossier de la correction souhaitee :

```bash
npm install
npm start
```

Pour lancer les tests :

```bash
npm test
```

Pour verifier le build :

```bash
npm run build
```
