# Challenge Angular - Juillet

Ce dossier regroupe les enonces et les helpers du challenge Angular de juillet.

## Structure

- `enonces/level-1.md` : sujet du Level 1.
- `enonces/level-2.md` : sujet du Level 2.
- `enonces/level-3.md` : sujet du Level 3.
- `helpers/` : aides fournies avec les enonces.

Les corrections sont organisees dans un projet Angular separe, avec une branche par niveau :

- `master` : correction du Level 1.
- `level-2` : correction du Level 2.
- `level-3` : correction du Level 3.
